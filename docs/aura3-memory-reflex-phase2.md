# AURA — memory and Reflex evidence
Date: 2026-10-12

## Long-term knowledge
Founder-only chat context now incorporates ranked, deduplicated lessons from the persistent `aura_lessons` table. Public chat is isolated from global founder lessons. Every retrieved item is flagged `stored-lesson-unverified`; repeated observations are not falsely represented as objective proof. No embeddings, remote requests or paid API are required.

## Reflex
Decision IDs are generated by native inference assessment; only an outcome reporting that precise ID is linked to it. Migration 15 persists these observations in `aura_reflex_observations`. The status dashboard reports distribution, failures and provenance. Labels supplied by untrusted code do not self-certify as verified. There is **no trained or calibrated policy yet**. Further work must introduce model-independent held-out evaluation and verifiable Capability Fabric receipts.
