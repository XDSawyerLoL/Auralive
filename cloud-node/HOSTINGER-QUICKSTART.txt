AURA Cloud Node — Hostinger 1.2

Réglages recommandés :
- Framework : Other
- Node.js : 22.x
- Répertoire racine : ./
- Entry File : server.js
- Installation : npm install --omit=dev
- Démarrage : npm start
- Output directory : vide

Architecture de démarrage :
- server.js = gateway Node natif sans dépendance, public sur 0.0.0.0:3000
- AURA/Fastify = runtime interne sur 127.0.0.1:3001
- si Fastify/MySQL échoue, le gateway reste en ligne et affiche le diagnostic au lieu d'un 503

Après déploiement :
- /                -> dashboard AURA ou page gateway de diagnostic
- /healthz         -> santé AURA/gateway
- /__aura_gateway  -> diagnostic garanti du gateway public
- /api/bootstrap/status -> état du noyau AURA

Variables fonctionnelles (pour activer le noyau complet) :
NODE_ENV=production
DB_HOST=...
DB_PORT=3306
DB_USER=...
DB_PASSWORD=...
DB_NAME=...
AURA_CLOUD_TOKEN=...
AURA_EVOLUTION_CANARY_TOKEN=...
