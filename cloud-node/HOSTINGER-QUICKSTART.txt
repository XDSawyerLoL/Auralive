AURA Cloud Node — Hostinger 2.1.0 — ZERO COST

Réglages :
- Framework : Other
- Node.js : 22.x
- Répertoire racine : ./
- Entry File : server.js
- Installation : npm install --omit=dev
- Démarrage : npm start
- Output directory : vide

Garantie financière :
- AURA_ZERO_COST_MODE=true est la valeur par défaut et doit rester activée
- aucun fallback Gemini/OpenAI distant potentiellement facturable
- Expert Bridge externe bloqué même si une ancienne clé existe dans Hostinger
- TTS Gemini Cloud bloqué ; voix Mairaiy via Providence/Kokoro ff_siwis, route publique bornée et sans facturation API
- nœuds Runtime déclarés payants, coût > 0 ou modèles Ollama :cloud exclus du Mesh
- sans worker local/gratuit disponible, AURA reste en mode natif/offline plutôt que de dépenser

Architecture de démarrage :
- un seul process Node
- un seul listener public : 0.0.0.0:3000
- Fastify est embarqué dans le même process via injection interne
- aucun port interne 3001
- MySQL démarre en arrière-plan et ne bloque jamais l’interface
- timeout connexion MySQL : 5 s par défaut

Après déploiement :
- / -> interface AURA
- /healthz -> état runtime
- /__aura_gateway -> état du gateway/application
- /api/bootstrap/status -> état du noyau cognitif
