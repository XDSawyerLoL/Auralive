# Recherche traçable

Cette compétence est une procédure native AURA. Son comportement compilé est défini dans `src/agent_skills.js` et non par l'exécution de ce document. Aucun script externe n'est chargé.

## Procédure

1. Interroger la mémoire et les références déjà disponibles localement.
2. Identifier les questions ouvertes sans inventer les réponses.
3. Si autorisé séparément, consulter des sources publiques officielles sans frais et dans les quotas.
4. Distinguer information vérifiée, revendication d'un tiers et incertitude.

## Porte de validation

Sources, dates de consultation, désaccords et degré de vérification. Une déclaration de l'agent, seule, n'est pas une preuve.

## Politique immuable

Budget : **0 €**. Aucune nouvelle API payante, aucun installateur, aucune commande shell automatique, aucun accès à un compte ou envoi de document sans autorisation, aucun déploiement implicite. Les étapes restent **pending** jusqu'à vérification instrumentée.
